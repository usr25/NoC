This folder contains different documents for the engine's openings, used for testing or for regular play.

PGN files:
- opening_suite.pgn: Used for standard testing
- sf_opbook.pgn: Openings used by stockfish. Much larger than opening_suite.pgn

Book files:
- [Human.bin](https://digilander.libero.it/taioscacchi/programmi/saros-page.html): Exotic openings, on the weaker but fun side.
- [komodo.bin](https://komodochess.com/downloads.htm): Opening book of komodo, multiple strong openings.
